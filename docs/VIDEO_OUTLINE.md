### 第 2 集 · 微信小程序移动端《用户视角的检前检后》（8–10 分钟，390×844）

1. **外壳（30s）**：`#/patient`；顶部「红创 · 健康中心 / H5 小程序演示」+ 铃铛 + 体检人头像；底部 tab **首页 / 预约 / 导检 / 报告 / 我的**。
2. **首页导流（1 分钟）**：Hero「秋日健康关怀计划」→「开启健康计划」；4 大服务卡（预约体检 / 单位团检 / 智能导检 / 体检报告）+ 移动端 4 宫格；精选套餐卡；健康课堂。
3. **问卷 → 对比 → 下单（3 分钟，本集核心）**
   - 检前问卷：3 个合成下拉（既往史 / 用药记录 / 家族史）+ 6 个多选项（久坐、熬夜、想了解血糖、关注甲状腺、关注骨骼、以上均无）→「完成问卷并生成参考方案」→「使用方案继续预约」自动写入加项；旁白点出「规则推荐不构成医学适应证」。
   - 套餐对比：勾两个套餐 →「对比已选套餐（2）」（≥2 才可点）→ 矩阵含每项「检查意义」→「选择此套餐」回填。
   - 预约表单：体检人 / 院区 / 搜索套餐 / 取消非必检项（必检「一般检查」为禁用）/ 加项（甲状腺彩超 ¥120、糖化血红蛋白 ¥65、骨密度 ¥95）/ 14 天日期快选（自动跳过周末）/ 时段；容量条「当日全院剩余 X / 80 个预约名额」→ 勾选「已阅读预约须知，确认本次为本地模拟预约」→「确认预约」。
   - **校验特写（务必录 2 条失败提示）**：未勾须知「请先确认已阅读预约须知」；清空项目「请至少保留一个检查项目」；选周末 / 过去日期 / 约满各有一条真实文案。
4. **模拟支付与订单（1 分钟）**：「模拟支付」→ 弹窗明示「不会打开支付渠道或扣款」+ 微信支付 / 支付宝 / 单位结算 →「确认模拟付款」→ 待支付转待到检；补一段「改期」（重算号源）与「取消预约」（注明不发生真实退款）。
5. **团检入口（1 分钟）**：单位口令 `DEMO2026`（先演示一次错误口令）→ 单位横幅显示预算模式（固定套餐 / 定额自选 / N 选 M / 限额自选 / 无限额）+「亲属预约（专属价自费）」→ 单位预约日历（每格「余 N」/ 已过期 / 休息 / 不可约）→ 结算提示「单位承担 ¥X / 自费 ¥Y」。
6. **导检排队（1 分钟）**：**先说明患者端没有到检签到按钮**，签到由自助机或后台完成 → 导检页「建议下一站」「预计等候 6 分钟（演示估算）」+ 排队二维码 → 实时演示队列（等待中 / 正在叫号 / 已过号）→「加入演示排队」「结束此排队」。
7. **报告与档案（1.5 分钟）**：报告页「审核通过 · 示例报告」→ 检查记录切换 → 历次记录对比（最近 2 / 3 次）→ 免责行「本报告为合成演示数据，不能用于真实医疗决策」；「我的」：注册合成体检人（称呼须以"演示"开头、手机号标识须 `DEMO-` 开头）、习惯打卡与「申请健康随访」、健康好物「加入演示购物车」→「模拟结算」。
8. **收尾字幕**：支付、短信、微信推送、商城交易、身份登录均只改本地状态。

### 第 3 集 · 体检自助机《现场到检五步》（5–6 分钟，`#/kiosk`）

1. **外壳（40s）**：右上「中心院区 · 自助终端 A01」+「设备模拟就绪」；页签「体检自助服务 / 报告打印装订」；主菜单 4 卡（自助签到 / 体检预约 / 自助缴费 / 打印导检单）；首页三步「01 识别身份 → 02 确认信息 → 03 完成办理」。
2. **身份识别（1 分钟）**：三种方式均带「模拟」角标（电子健康码 / 身份证读卡 / 人脸识别）→「选择演示体检人」下拉 →「模拟识别并继续」；镜头停留屏上原文「真实读卡器、扫码器与摄像头未连接」；成功后副标题变「{姓名} · 演示身份已识别」。
3. **自助签到（1.5 分钟，本集核心）**：核对预约 → 左列表选单（选单同时同步院区）→ 右详情显示日期时段 / 院区 / 预约编号 / 项目标签 → **到检院区改选**（中心院区 → 东院区）→「确认签到」→「到检签到成功，已同步医护工作台。」并自动进入导检单屏。
   - 分支镜头：待缴费订单出现「前往模拟缴费」；锁定订单出现「订单已锁定，不能重复签到，请联系工作人员。」
4. **自助缴费（40s）**：「确认模拟支付」+「演示支付 · 不产生真实扣款」→ 支付方式落「自助机模拟扫码」→ 自动转签到。
5. **自助预约（1.5 分钟）**：套餐卡（按性别年龄与线上开放过滤）→ 套餐项目勾选（必检禁用）→ 增加检查项目 → 检前问卷（「提交自助机问卷」自动带入推荐项目 /「跳过自助机问卷」）→ 日期快选 + 预约院区 + 时段 → 容量条 →「创建模拟预约」→「预约已创建，请选择新订单完成模拟缴费。」
6. **打印导检单（40s）**：「A4 导检单 · 1 页 / 纸质输出仅为模拟效果」→「模拟打印导检单」→ 进度「生成文件 → 模拟打印」→ 完成页「建议下一站：一层采血区」→「完成并退出」。
7. **隐私与超时（40s）**：右下「演示控制」→「模拟身份超时」→「本次会话已超时，演示身份已清除。」；说明 120 秒无操作自动退出、任何触摸重置计时。
8. **解说避坑**：自助机**没有**条码打印、弃检、改期、报告柜功能；条码在后台「打印任务与版式」和分检「采样与条码工作站」，弃检 / 改期在 `#/appointments` 订单详情，报告柜在 `#/reports`。

### 第 4 集 · 报告打印装订自助机《含故障演练》（4–5 分钟，`#/kiosk?mode=report`）

1. **入口（30s）**：右上「报告终端 R01」；主菜单 2 卡（打印体检报告 / 查看报告状态，同屏不同侧重）。
2. **可领范围（1 分钟）**：识别沈砚秋 → 屏头「仅审核通过的报告可打印」；列表区分「已审核 · 可领取」与「已领取 · 可补打」（补打镜头）；无报告兜底「您的报告暂未完成审核…可选择沈砚秋或江月白」。
3. **打印与装订（1 分钟）**：左侧 A4 预览（含「合成报告 · 演示专用」）→ 右侧「打印份数 1 / 2 份」+「完成打印后自动装订（模拟）」→「开始模拟打印与装订」→ 三段进度（生成文件 → 模拟打印 → 模拟装订）→ 完成页「2 份 · 模拟装订已完成 · 打印记录已同步」。
4. **四类故障（1.5 分钟，本集卖点）**：「演示控制 · 设备异常模拟」逐条切换并给出提示原文：
   - 纸张不足：「纸张余量不足，请补纸后重试。**打印任务尚未创建。**」
   - 卡纸：「打印机卡纸，请排除故障后重试。打印任务尚未创建。」
   - 离线：「设备离线，请恢复后重试。」同时签到与支付按钮被禁用。
   - 超时：会话倒计时归零清除身份（独立机制，不在故障按钮内）。
   - 恢复：「恢复设备并重试」→「设备已恢复，您的订单未被重复处理，可继续办理。」**切回报告列表证明订单仍是「已审核」、打印次数未增加**，讲清三层保护：故障时不派发打印事件、仅在最后一步触发一次、打印进行中禁用故障切换与恢复。
5. **联动收尾（30s）**：切后台 `#/reports`，该单转「已打印」、打印次数 +1、审计出现「报告自助终端完成模拟打印 …」。

### 第 5 集 · 管理后台（上）《体检业务主线》（12–14 分钟，按角色推进）

1. **前台登记员 · `#/appointments`（4 分钟）**
   - 指标条 + 搜索 / 状态 / 日期 / 院区组合筛选 →「新建预约」。
   - 「历次异常参考 · 合成历史」卡：A 类推颈动脉彩超、B 类推血脂复查、其他推健康教育咨询，勾选后进入计价行。
   - 展开「多套餐、单项折扣与适用规则」：去重计费（多套餐重复项目只计一次）、目标总金额反算折扣、必检 / 依赖自动带入、互斥与性别限制红字、婚姻适用警示需填「强制添加理由」；折扣低于角色授权下限被拦截。
   - 「确认预约」→ 新单待缴费并自动生成 3 条打印任务（导检单 / 项目单 / 检验条码）→ 行内「模拟收款」→「到检」。
   - 工具栏 8 入口各 30 秒：团检 CSV 导入（三步条 + `DEMO-P001` 证件校验 + 错误行下载）、项目与套餐规则（腹部 CT 互斥腹部彩超、必检禁止折扣）、团检订单与预算（固定 / 限额 / 无限额 + 预付款账本不能透支）、手工客户登记（仅收 DEMO 标识 + 客户类型 → 订单类型 → 导检区域映射）、打印任务与版式（批量生成 / 模拟失败重试 / 预览二维码）、改日检到期管理（先登记 → 预览 → 明确确认批处理）、导出原名单与替检名单。
   - 订单详情：换院区与改期（先跑号源校验）、加项、**弃检**、团检替检（保留原名单双向追踪）、克隆、锁定 / 解锁、取消。
2. **分检医生 · `#/exam`（3 分钟）**
   - 左列今日候检选人 →「带入上次结果（仍需人工复核）」或「填入正常示例」。
   - 数值校验特写：空腹血糖输入文字被拒「空腹血糖必须为数值型结果（mmol/L），不能提交文字。」
   - 「采样条码」→「采样与条码工作站 · 模拟」：标本类型、`DEMO-{体检号}-{类型}`、「模拟打印 / 补打」、「确认标本采集」。
   - 「分检扩展」：分级小结排序、内科问诊模板、本地图片 / 音频（512KB 上限）、检查申请单模拟重推与单项结果导出。
   - 异常链路：血糖 ≥ 7.8 必须勾「已复核异常结果…」并填分检小结才能提交 → 提交后**全局重大异常提醒弹窗**（任意页面）→ 填处理结果 + 是否进入随访 → 保存处置生成 A 类任务。
   - 补一段「撤销未审核的分检提交」，说明进入审核后该入口自然消失。
3. **总检医生 · `#/review`（3 分钟）**
   - 列表排序：危急优先、超期置顶，勾「仅看超期报告」。
   - 结果核对表（未回传标红、需复核）→「生成关联异常综合建议」（本地规则，非 AI）→ 责任医生下拉即时保存 →「通过初审 → 通过主检 → 通过总检」→ 报告自动锁定。
   - 再来一遍「驳回重检」（原因必填，退回后需重新分检提交）；镜头切 `#/quality` 的「驳回质控」看原因分布，形成呼应。
   - 各 30 秒：审核排班与「分配当前订单」、人工标记重大阳性、订单类型与复查项目、建议上移下移排序、异常词条匹配与未匹配片段提示。
4. **平台管理员 · `#/queue` + `#/reports`（3 分钟）**
   - 导检：tab 切科室队列 →「呼叫下一位」/ 行内「呼叫 / 重呼」/ ↑↓ 调序 /「过号」（原因必填）→ 右侧过号队列「召回入队」/「完成出队」/「手动入队」；排序模式「空腹项目优先」立即重排；勾「隐藏姓名中间字」后打开 `#/queue?screen=1` 验证大屏隐私；批量开启 / 关闭队列与清空（历史保留）。

## 3. 旁白红线（必须说 / 不能说）

**必须出现的口径**

- 支付 / 退款 / 余额 / 发票 / 会员卡抵扣 → 「模拟记账，不产生真实资金流转」
- 短信 / 电话 / 邮件 / 微信通知 → 「仅本地记录，未实际发送」
- 身份识别 / 双照核对 / 签名 → 「合成身份、抽象示意、无法律效力，不采集生物特征」
- 医学规则 / 问卷 / 评估 / 关联建议 / 词条 → 「有限合成规则或固定样例，不构成诊断、治疗或医学适应证」
- HIS / LIS / PACS / 医保 / 物流 / 打印机 / 装订机 / 读卡器 → 「未连接真实接口与设备，Mock 无外部请求」
- 角色权限 → 「浏览器内可改，不是安全边界，生产鉴权须服务端强制」

**禁止宣称**：真实小程序已发布、实机打印 / 装订通过、性能与并发达标、等级保护或密码学合规、945 项功能全部完成、可用于临床生产验收。
